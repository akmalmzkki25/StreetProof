# MaintainX

Date: 2026-10-20 | Status: Proposed / research-based | Document ID: C-01

[English / Bahasa Indonesia](../../../id/01-research/competitors/maintainx.md)

## Relevance

MaintainX is a direct alternative for operators seeking work orders and broader maintenance management. Its official help page documents external request portals, so no-login reporting cannot be claimed as StreetProof's invention.

## Evidence reviewed

| Area | Reviewed vendor claim and limit |
| --- | --- |
| Reporting | External users submit through links or QR codes without logging in; optional status email. |
| Review | Administrators approve or decline incoming work requests. This is request authorization, not automatically final repair acceptance. |
| Maintenance depth | Work orders, procedures, inventory, time/cost tools and API appear across plans. Exact pilot configuration remains untested. |
| Plan constraints | The help page places external portals in Premium/Enterprise. Free requester accounts are distinct from a no-login portal. |
| Unverified | Indonesian purchasing terms, required completion evidence policy, cross-report merge and implementation effort. |

- [Request portal documentation](https://help.getmaintainx.com/set-up-a-request-portal)

## Commercial reading

The accessed pricing page displays Basic $0, Essential $20/user/month annually or $25 monthly, and Premium $65 annually or $75 monthly. Enterprise is quote-based. These are displayed USD list prices, not an Indonesian quote, tax-inclusive total or like-for-like StreetProof price. [Pricing](https://www.getmaintainx.com/pricing)

## Comparable test

Test a tenant report through the portal, attach a location-specific photo, and follow the reporter's update visibility. Then distinguish approving the request from accepting the technician's completion. Finally export a rejected and reopened case and check who can see each record.

## Implication for StreetProof

StreetProof should offer a smaller setup and a tested operator-effort advantage or act as an intake companion. If MaintainX configuration already meets the buyer's needs, adding StreetProof may create duplicate records and support work. Do not claim MaintainX lacks human verification or AI without a targeted check.
