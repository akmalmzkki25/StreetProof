# UpKeep

Date: 2026-10-20 | Status: Proposed / research-based | Document ID: C-02

[English / Bahasa Indonesia](../../../id/01-research/competitors/upkeep.md)

## Relevance

UpKeep is a direct CMMS alternative, including for a small single-site team. Its public offering already connects reporting, work orders, mobile close-out and AI. StreetProof must therefore compare actual task effort rather than frame UpKeep as only an enterprise tool.

## Evidence reviewed

| Area | Reviewed vendor claim and limit |
| --- | --- |
| Reporting | Pricing lists free unlimited requester users; external request portal is listed with Professional. Internal requester access and external access need separate checks. |
| Evidence | Work-order page describes photo attachments, before/after close-out and signature capture. |
| Work management | Routing, assignment, audit trails, parts and labor tools are advertised with plan differences. |
| AI | Nova appears in the plan offering, including close-out and data-assistance features. Its accuracy on Indonesian reports is untested. |
| Unverified | Exact duplicate preservation, supervisor acceptance policy, regional service terms and configured permission behavior. |

## Commercial reading

The accessed pricing page displays Essential $24/user/month and Premium $55/user/month; Professional and Enterprise require quotation. Billing selection, tax, implementation and AI-credit usage must be confirmed in a specific offer. The page also lists onboarding services, so subscription alone is not a complete cost comparison. [Pricing](https://upkeep.com/pricing/)

## Comparable test

Compare an unclear incoming report, technician before/after upload and a supervisor rejection. Measure operator edits and technician input time. Check whether a free requester can see only their own cases and which plan enables an unauthenticated external route.

## Implication for StreetProof

The relevant wedge is a narrower, lower-burden workflow for a specific site. Free reporter access and mobile proof already exist in the advertised offer. Recheck total cost and setup before saying StreetProof is cheaper or faster. An export companion must avoid two conflicting assignment records.

Next action: P/E/Q record plan, configuration, observed effort and unanswered questions in an authorized trial before any purchase recommendation.
